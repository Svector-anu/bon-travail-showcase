Built on Arc testnet with Aeon and Arc Studio

Bon Travail.
Work that pays itself.

An autonomous agent posts small tasks. A person answers. The server checks the answer against the Arc chain itself, then pays the USDC reward or refunds it. Every outcome gets a public receipt.

The loop

There are no judgment calls anywhere: a correct answer is one that matches the chain exactly.

  1. 1

    Agent posts

    Picks a real Arc transfer, reserves the 1 USDC reward, opens the task.

  2. 2

    Human claims

    A ten-minute lock, bound to the claimer's wallet.

  3. 3

    Answer

    Who received the USDC, and exactly how much.

  4. 4

    Chain checks

    The server re-reads Arc over RPC: checksummed address, 6-decimal amount, exact match.

  5. 5

    Pay or refund

    Match pays the worker. No match by the deadline refunds the agent.

  6. 6

    Receipt

    Immutable, public, sealed with a sha256 digest.

Rules
Only the agent can fund, release or refund. A task can never be both paid and refunded. 1 USDC cap per task.
  • The deploy was driven by this skill's own turn script, run from the project.
  • Then Aeon itself ran the skill on GitHub Actions with the Claude harness: one run started an Arc Studio turn, a second run picked it up and settled it.
  • Along the way it hit a real sandbox bug: the skill could not save its state in read-only mode. The fix is one line, verified on Aeon, in PR #117.
proofwork-loopReady, waits for a public URL

The agent's heartbeat. Every ten minutes it triggers one sweep: publish new work, release lapsed claims, verify, pay, expire and refund.

  • It can call exactly one endpoint. It never decides who gets paid; the server does, by exact comparison.
  • Its token never appears on a command line, and it treats every string in a response as data, not instructions.

  • One state machine. Every move goes through one function; anything illegal throws.
  • Events are append-only and receipts can't be edited, enforced by the database itself.
  • Payments are idempotent: a retry can never pay twice.
  • Caps: 1 USDC per task, 10 per day, 5 outstanding in escrow.
  • The right answer stays hidden until the task settles.
